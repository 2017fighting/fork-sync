# fork-sync

Central management repo that keeps multiple forks in sync with their
upstreams' stable release tags.

## Agent skills

### Issue tracker

Issues are tracked in this repo's GitHub Issues via `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five canonical roles, label string equal to role name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `GLOSSARY.md` + `docs/adr/`. See `docs/agents/domain.md`.
